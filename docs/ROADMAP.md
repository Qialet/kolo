# Roadmap Kolo

Текущий фокус: MVP — интерактивный изометрический город с живой симуляцией и админ-действиями.

## Решения, согласованные с пользователем
- Город процедурный «в духе Врачара» (~1×1 км); импорт реального OSM-района — фича позже.
- Рендер: React Three Fiber + drei, ортографическая изометрическая камера.
- Симуляция на сервере (Nest), рассылка по WebSocket; фронт интерполирует.
- Prisma 8 RC, pnpm + Turborepo, бренд Kolo, вымышленные партнёры и агрегатор.

## MVP
- [x] Монорепо: pnpm workspaces, turbo, Nest 12, Next 16, Prisma 8, официальные скилы
- [x] packages/contracts: enum'ы статусов, wire-формат кадров, zod-схемы REST
- [x] packages/sim: генератор города (улицы, бульвары, кварталы, депо, остановки, адреса)
- [x] packages/sim: светофоры (сербская фаза красный+жёлтый), IDM, конфликты на перекрёстках
- [x] packages/sim: такси, автобусы, фон, заказы, диспетчеризация, отмены, неявки, возражения
- [x] packages/sim: жизненный цикл (ремонт, смены водителей), тесты и прогон на дедлоки
- [ ] api: контракт Prisma (партнёры, парки, машины, водители, заказы, события, споры), миграция, сид
- [ ] api: модуль симуляции + WebSocket-шлюз (кадры 10 Гц, KPI 1 Гц, события)
- [ ] api: REST — парки, машины (смена статуса), заказы (создать, отменить, назначить), споры, светофоры, управление симуляцией
- [ ] web: shadcn, тема Kolo, шрифты, токены цветов
- [ ] web: изометрическая сцена — город, дороги, разметка, здания, деревья, депо, остановки
- [ ] web: машины, такси, автобусы с интерполяцией; светофоры с живыми фазами
- [ ] web: выбор объектов — такси (маршрут A→B, ETA, дистанция), светофор (обратный отсчёт), парк, здание, автобус
- [ ] web: панели — KPI, лента событий, список заказов, флот, таймлайн заказа, поиск
- [ ] web: админ-действия из инспектора (статус машины, отмена/назначение заказа, режим светофора, скорость/плотность)
- [ ] docs: ARCHITECTURE, DOMAIN, DESIGN, SIMULATION

## Фичи после MVP
- [ ] Тепловая карта спроса и surge-зоны с коэффициентом цены
- [ ] Смена дня и ночи (фары, окна, плотность трафика и спроса по времени суток)
- [ ] Перемотка истории (replay): треки машин и спорный заказ за последний час
- [ ] Роли и авторизация: админ агрегатора, менеджер парка (видит свой парк), диспетчер
- [ ] Импорт реального района Белграда из OpenStreetMap (здания по building:levels, улицы)
- [ ] Перестроение полос внутри сегмента, кольцевая развязка (Славия), пешеходы на зебрах
- [ ] Swagger/OpenAPI для REST, e2e-тесты API, Playwright-сценарии фронта
- [ ] Хранение телеметрии (TimescaleDB или партиционирование) для аналитики и replay
- [ ] Мобильный «водительский» эмулятор: принять/пропустить заказ вручную
