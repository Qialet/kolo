# Roadmap Kolo

Текущий фокус — два трека параллельно: крупный этап «Белград» (реальный город вместо процедурного) и фичи после MVP, не зависящие от карты.

## Решения, согласованные с пользователем
- Город — реальный Белград (здания, улицы, остановки, линии автобусов и маршруток) вместо процедурного «Врачара».
- Позиции общественного транспорта — симуляция по открытому расписанию GTFS, не GPS: открытого real-time API в Белграде нет.
- Неофициальные API (реверс мобильных приложений) не используем; данные OSM и GTFS только офлайн, без запросов в рантайме.
- Рендер: React Three Fiber + drei, ортографическая изометрическая камера.
- Симуляция на сервере (Nest), рассылка по WebSocket; фронт интерполирует.
- Prisma 8 RC, pnpm + Turborepo, бренд Kolo, вымышленные партнёры, локальный Postgres без Docker.

- [x] Полировка: дворы, припаркованные машины, прогресс по пробегу, вместимость парков, подсветка партнёра, dev-перезапуск

## Белград — где продолжать
- Работа идёт в ветке feat/belgrade (в main не влита); планы 1 (дороги) и 2 (здания, места, депо, приложение на файле района) выполнены.
- Осталось 3 плана, каждый писать через superpowers:writing-plans в docs/superpowers/plans, не более 100 строк:
- План 3 — GTFS: остановки, рейсы, трассы, часы Europe/Belgrade, праздники, кнопка синхронизации, инспекторы линии и остановки, троллейбусы (написан: 2026-10-22-belgrade-3-transit.md).
- План 4 — трамваи по railway=tram. План 5 — LOD, отсечение, бюджет кадра, финальные доки.
- Скриншоты: playwright-core в корне (системный Chrome, channel chrome).

## Белград — согласовано (детали в docs/superpowers/specs/2026-10-21-belgrade-design.md)
- Около 5 км², только правый берег Савы: Калемегдан — Храм Светог Саве, Савамала — Ташмајдан; расширяемо.
- Часы симуляции — реальное время Europe/Belgrade; при ускорении — кнопка синхронизации.
- Процедурный генератор удаляется; файл района в git, клиенту — статическим ассетом с хэшем версии.
- Все виды транспорта; трамваи — отдельным этапом после автобусов. LOD обязателен.
- Ничего не скачивать и не устанавливать без явного разрешения пользователя.

## Белград 0 — данные (сырьё в data/raw, вне git)
- [x] GTFS data.gov.rs «Градски јавни превоз у Београду», версия 24 от 31.10.2025, действует до 31.12.2026; сервисы RD (будни), S (суббота), N (воскресенье и праздники)
- [x] В рамке: 146 остановок, 10 трамвайных, 6 троллейбусных, около 110 автобусных линий (включая ночные N); около 22 тыс. рейсов в будний день
- [x] Минибусов как route_type в фиде нет: минибусы — EKO1 и EKO2 (электрические), справочник в импорте
- [x] calendar_dates кончаются маем 2025: праздники Сербии (в т. ч. православная Пасха) считать самим, на праздник — сервис N
- [x] OSM — Overpass по рамке с запасом 200 м, снимок 21.10.2026: 6,3 тыс. зданий (89% с этажностью), 282 светофора, 39 путей колец, 400 запретов поворотов, 252 turn:lanes, 212 путей с trolley_wire, PTv2-маршруты
- [x] Лицензии: ODbL (атрибуция OSM на карте), Serbian Open Data License (атрибуция Градской управы)

## Фичи после MVP — делаются параллельно с Белградом, от карты не зависят

- [ ] Тепловая карта спроса и surge-зоны с коэффициентом цены (зоны — сетка ячеек, не кварталы, чтобы пережить перенос)
