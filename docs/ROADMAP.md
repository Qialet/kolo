# Roadmap Kolo

Текущий фокус: MVP готов и проверен скриншотами; дальше — полировка MVP и фичи по согласованию с пользователем.

## Решения, согласованные с пользователем
- Город процедурный «в духе Врачара» (~1×1 км); импорт реального OSM-района — фича позже.
- Рендер: React Three Fiber + drei, ортографическая изометрическая камера.
- Симуляция на сервере (Nest), рассылка по WebSocket; фронт интерполирует.
- Prisma 8 RC, pnpm + Turborepo, бренд Kolo, вымышленные партнёры, локальный Postgres без Docker.

- [x] packages/sim: светофоры (сербская фаза красный+жёлтый), IDM, конфликты на перекрёстках
- [x] packages/sim: такси, автобусы, фон, заказы, диспетчеризация, отмены, неявки, возражения
- [x] packages/sim: жизненный цикл (ремонт, смены водителей), тесты и прогон на дедлоки
- [x] api: контракт Prisma, миграция init, автосид, закрытие «осиротевших» заказов
- [x] api: модуль симуляции и WebSocket-шлюз (кадры 10 Гц, KPI 1 Гц, события, заказы)
- [x] api: REST — парки, машины (статус, история), заказы (создать, отменить, назначить), споры, светофоры, симуляция
- [x] web: shadcn (Base UI, nova), тема Kolo, токены акцентов
- [x] web: изометрическая сцена — дороги, разметка, зебры, здания с окнами, деревья, депо, остановки

- [x] web: выбор объектов — такси (маршрут, A/B, ETA, дистанция), светофор (обратный отсчёт), парк, здание, автобус, остановка, заказ
- [x] web: панели — KPI, лента событий, вкладки заказов/флота/парков/возражений, трекер заказа, поиск Ctrl+K

## Полировка MVP (следующие шаги)
- [ ] Дворы: невысокие дворовые постройки, больше деревьев, детские площадки
- [ ] Припаркованные машины вдоль бордюров на местных улицах
- [x] Прогресс поездки по фактической длине маршрута
- [x] Вместимость парка в БД синхронизировать с числом мест сгенерированного двора

- [ ] Мобильная и узкая раскладка панелей
- [x] Перезапуск Nest при изменении packages/sim в pnpm dev

## Фичи после MVP (согласованы как идеи)
- [ ] Тепловая карта спроса и surge-зоны с коэффициентом цены
- [ ] Смена дня и ночи (фары, окна, плотность трафика и спроса по времени суток)

- [ ] Роли и авторизация: админ агрегатора, менеджер парка (видит свой парк), диспетчер
