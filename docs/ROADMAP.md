# Roadmap Kolo

Текущий фокус: этап «Белград» — реальный город из OSM и GTFS вместо процедурного района. Фичи после MVP ждут.

## Решения, согласованные с пользователем
- Город — реальный Белград (здания, улицы, остановки, линии автобусов и маршруток) вместо процедурного «Врачара».
- Позиции общественного транспорта — симуляция по открытому расписанию GTFS, не GPS: открытого real-time API в Белграде нет.
- Неофициальные API (реверс мобильных приложений) не используем; данные OSM и GTFS только офлайн, без запросов в рантайме.
- Рендер: React Three Fiber + drei, ортографическая изометрическая камера.
- Симуляция на сервере (Nest), рассылка по WebSocket; фронт интерполирует.
- Prisma 8 RC, pnpm + Turborepo, бренд Kolo, вымышленные партнёры, локальный Postgres без Docker.

## MVP и полировка — готово
- [x] Монорепо, contracts, sim (город, светофоры, IDM, агенты, заказы, жизненный цикл), api (Prisma, WebSocket, REST)
- [x] web: изометрическая сцена, выбор объектов, панели, админ-действия, адаптив; docs
- [x] Полировка: дворы, припаркованные машины, прогресс по пробегу, вместимость парков, подсветка партнёра, dev-перезапуск

## Белград — открытые вопросы (согласовать до этапа 1)
- Границы: предлагается начать с ~2×2 км вокруг Славии (Врачар, центр), потом расширять.
- Процедурный генератор: оставить для быстрых тестов sim или удалить после переноса.
- Доставка города клиенту: статический файл в бандле или отдача через API с хэшем версии.
- Трамваи и троллейбусы: включать сразу или сначала только автобусы и маршрутки.

## Белград 0 — данные
- [ ] Скачать GTFS Белграда с data.gov.rs; выяснить, какой фид городской, а какой пригородный, и свежесть
- [ ] Найти в GTFS маршрутки (минибусные линии): номера, остановки, интервалы
- [ ] Выгрузка OSM района (Geofabrik Serbia), зафиксировать дату снимка
- [ ] Лицензии: атрибуция ODbL на карте, условия лицензии GTFS с data.gov.rs

## Белград 1 — пайплайн импорта
- [ ] Офлайн-конвертер OSM + GTFS в компактный файл района, версионируемый в git или артефакт сборки
- [ ] Проекция WGS84 в локальные метры (x — восток, z — юг) от центра района
- [ ] Сервер и клиент строят город из одного файла вместо seed; сверка версии при подключении
- [ ] Тесты импорта: связность графа, остановки привязаны, нет пустых линий

## Белград 2 — дорожный граф и движение
- [ ] Улицы из highway: класс, число полос (lanes), oneway, ширина; полилинии вместо прямых отрезков
- [ ] Перекрёстки любой степени и любых углов: коннекторы, конфликты, поворотные ограничения
- [ ] Светофоры по highway=traffic_signals, фазы по осям; нерегулируемые — по приоритету дорог
- [ ] Кольцевые развязки (Славия, Autokomanda): въезд с уступкой, движение по кругу
- [ ] Перестроения полос внутри сегмента (многополосные реальные улицы)
- [ ] IDM и ограничение скорости на кривых, maxspeed из OSM
- [ ] Прогон без коллизий и дедлоков на реальном графе

## Белград 3 — здания и застройка
- [ ] Контуры зданий OSM, высота по building:levels или height, дефолт по типу здания
- [ ] Рендер произвольных полигонов (экструзия), окна шейдера по реальной высоте этажей
- [ ] Адреса из addr:*, точки подачи у ближайшего бордюра нужной стороны
- [ ] Парки, площади, зелень, вода (Sava, Dunav) из landuse, leisure, natural
- [ ] Точки притяжения из POI: вокзалы, ТЦ, больницы, университеты, рынки
- [ ] Деревья, дворовый декор, припаркованные машины — процедурно поверх реальных кварталов

## Белград 4 — общественный транспорт
- [ ] Остановки из GTFS stops (названия латиницей), привязка к полосе своего направления
- [ ] Линии автобусов из GTFS routes и shapes, сверка с OSM route relations (PTv2)
- [ ] Порядок остановок по каждому направлению из stop_times, конечные и развороты
- [ ] Маршрутки: линии и их остановки из GTFS; если их нет — OSM relations или ручной справочник
- [ ] Выпуск машин по интервалам и рейсам расписания по времени симуляции
- [ ] Карманы остановок из OSM (bus_bay) или эвристика по ширине улицы
- [ ] Трамваи и троллейбусы — по решению открытого вопроса
- [ ] UI: инспектор линии (остановки по порядку, интервал, следующий рейс), пометка «по расписанию»

## Белград 5 — домен и производительность
- [ ] Депо партнёров на выбранных реальных участках, вместимость из двора
- [ ] Спрос по весам POI, остановок и плотности застройки
- [ ] Миграция БД: координаты парков, сброс заказов процедурного города
- [ ] Камера, LOD и отсечение для района больше 1 км; бюджет кадра и шага симуляции
- [ ] Обновить SIMULATION, ARCHITECTURE, DESIGN, DOMAIN под реальный город

## Фичи после MVP (согласованы как идеи)
- [ ] Тепловая карта спроса и surge-зоны с коэффициентом цены
- [ ] Смена дня и ночи (фары, окна, плотность трафика и спроса по времени суток)
- [ ] Перемотка истории (replay): треки машин и спорный заказ за последний час
- [ ] Роли и авторизация: админ агрегатора, менеджер парка (видит свой парк), диспетчер
