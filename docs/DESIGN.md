# Айдентика и UI Kolo

## Идея
- Kolo — «колесо» по-сербски и народный хоровод: круглый логотип-колесо в жёлтом на чернильном квадрате.
- Город — монотонный холодный сланец с мягкими градиентами; цвет получают только смысловые объекты.
- Референс — изометрическая логистическая панель (screenshot.png в корне), но со своей таксомоторной спецификой.

## Палитра мира
- Асфальт сланцево-серый, вся земля вне дорог — светлый тротуар; здания — градиент от светлого верха к серо-голубому низу, общественные чуть голубее, храмы теплее.
- Окна — сетка в шейдере: ряды по реальной высоте этажа здания (высота / этажность), колонки каждые 2,7 м вдоль стены, первый этаж глухой.
- Деревья — приглушённый шалфей; парки, газоны, лес — оттенки бледно-зелёного; вода (Сава, фонтаны) — светло-голубая; плазы и парковки — светлее тротуара.
- Детские площадки — тёплый песочный настил и приглушённые пастельные снаряды; дворовые гаражи — серо-голубые, без окон.
- Фон вокруг района — светлый радиальный градиент.

## Акценты (единые для 3D и UI, токены в globals.css и lib/palette)
- Такси — жёлтый Kolo, главный объект; плафон показывает состояние.
- Автобусы, остановки, карманы — кобальт; троллейбусы — бирюзовые с двумя штангами, минибусы (EKO) — короткие светло-кобальтовые.
- Трамваи — тёмный индиго, вагон из секций по следу передней точки (клиент хранит след каждого трамвая): CAF Urbos 3 — 5 секций, Tatra KT4 — 2; пантограф на средней секции; клик по любой секции выбирает трамвай.
- Контактная сеть — пара тонких графитовых линий на высоте 5,6 м над бордюрной полосой улиц с trolley_wire и поворотами между ними; трамвайный провод — одна линия на 6,0 м над осью пути.
- Пути — два стальных рельса с колеёй 1,0 м по рельсовым полосам и кривым узлов; тёплое балластное полотно 2,6 м только там, где путь не лежит на полосе улицы; у остановок только для трамваев — светлая платформа 2,2 × 30 м назад от точки остановки, со стороны пути без полос машин.
- Асфальт и разметка узлов строятся только по автомобильным подходам; рельсовый подход на общей полосе своего светофорного столба не получает.
- Маршрут выбранного автобуса и трасса выбранной линии — цветом линии из GTFS; номер линии — плашка её цветов.
- Парки партнёров — фиолетовый (площадка, рамка, метка), сервисные боксы — коралловые ворота и гараж.
- Фильтр партнёра: его такси получают пульсирующее фиолетовое кольцо (размер почти постоянен на экране), такси других партнёров выцветают к тону асфальта.
- Точка A — изумрудный пин, точка B — чернильный пин; цель без заказа — фиолетовый.
- Светофоры — красный, янтарный, зелёный (эмиссия) и подкрашенные стоп-линии на подходах.
- Ошибки и отмены — розово-красный; фоновые машины — нейтральные белые и серые.

## Масштаб и читаемость
- Улицы и дома в реальных размерах из OSM, машины отрисованы на 15% крупнее — ради читаемости в изометрии.
- Подписи POI — только места с весом от 2; внизу карты атрибуция «© OpenStreetMap contributors · Расписание: data.gov.rs, Grad Beograd».
- Маршрут рисуется поверх зданий (как в навигаторах), с белой подложкой.

## Раскладка консоли
- Сверху: логотип, поиск Ctrl+K (такси, заказы, парки, линии, остановки, адреса), переключатель партнёра, кнопка «Заказ», симуляция (скорость, пауза, трафик, спрос), Live-часы Белграда с типом дня и кнопка «Синхронизировать» (часы ушли больше чем на 30 с при скорости не выше ×1), лента событий, профиль.
- Слева сверху: четыре KPI-карточки (такси на линии, активные заказы, время подачи, выручка смены).
- Справа: колонка управления картой (зум, поворот, домой, подписи) и инспектор выбранного объекта.
- Снизу слева: трекер заказа по шагам; снизу справа: вкладки заказов, флота, парков, возражений.
- Панели — «стекло» (glass-panel), скругление 2xl, мягкая тень.
- Адаптив: меньше lg — поиск иконкой, KPI горизонтальной лентой; меньше xl — трекер только карточкой заказа, меньше 2xl — компактные шаги.
- Телефон (меньше md): шапка из иконок, инспектор — нижний лист, панель вкладок на всю ширину и свёрнута по умолчанию, трекер скрыт.

## Компоненты
- shadcn/ui на Base UI (стиль nova): у триггеров проп render вместо asChild, у ToggleGroup значение массивом.
- Иконки lucide; бейджи статусов — StatusBadge с тонами taxi, bus, depot, service, success, danger.
- Трамвай, трамвайная линия в поиске и остановка только для трамваев — иконка TramFront; поиск линий понимает слова «трамвай», «троллейбус», «автобус».
- Строки интерфейса на русском; названия улиц и мест — сербские латиницей.
